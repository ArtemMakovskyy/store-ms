isPresent() / isEmpty() — перевірка на наявність значення

get() — отримати значення (⚠️ кидає виняток, якщо значення відсутнє)

ifPresent(Consumer) — виконати дію, якщо значення є

orElse(defaultValue) — повертає значення або дефолтне

orElseGet(Supplier) — повертає значення або викликає функцію

orElseThrow() — кидає виняток, якщо значення відсутнє

map(Function) — трансформує значення, якщо воно є

flatMap(Function) — аналог map, але функція повертає Optional


🌱 Основні типи Optional

Тип Optional	Опис	Коли використовувати

Optional.empty()	Порожній контейнер, який не містить жодного значення	Коли потрібно явно повернути “нічого”, але уникнути null

Optional.of(T value)	Створює Optional, що містить НЕ-null значення	Коли ви впевнені, що значення не є null

Optional.ofNullable(T value)	Створює Optional, який містить значення або є порожнім, якщо значення — null	Коли значення може бути null
